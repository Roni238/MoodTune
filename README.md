# MoodTune
Веб-приложение с ИИ-помощником, созданное для поддержки эмоционального состояния. Оно помогает пользователям разбираться в своих чувствах, слушает без осуждения и помогает пользователям.

## Предпросмотр https://mood-tune-three.vercel.app/

## Начало работы

```
$ npm install
$ npm run dev
```

Стек - Vue, FSD, Pinia, TS, Supabase, vue-router, Vercel, ai Studio, БЭМ.
